# CRUDS

A simple and responsive inventory management web app that lets you Create, Update, Read, Delete, and Search for items using your browser's local storage.

## Features

- Create, Read, Update, Delete, and Search for any item
- Data is saved automatically using local storage, even after closing the browser
- Search by title or by category
- Count feature to manage the quantity of each product
- Simple and responsive interface that works on all screen sizes

## How to Use

- Open the project in your browser
- Enter the basic info about the product and the count of it
- Click the buttons to Create, Update, Delete, or Search for items
- Everything will be saved automatically until you delete it yourself

## Motivation

- Build a simple real-world CRUD application
- Show how local storage can replace a database for small projects
- Practice building a clean and responsive UI

## Installation

- No installation needed
- Just open the project in any modern web browser
- Local storage must be enabled in your browser settings

## Database

This project uses the browser's local storage which can store up to 5-10 MB of data. Everything is saved until you manually delete it.
